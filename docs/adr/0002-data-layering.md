# ADR-0002：数据分层——上游元数据 + 人工覆盖

- 状态：Accepted
- 日期：2026-09-07

## 背景

导航站需要「全量覆盖上游 322 个 AI 品牌」，同时又要提供人工精选的分类、中文名与简介。

## 决策

采用**两层数据 + 合并层**：

1. `src/data/icons.generated.ts`（脚本生成，禁止手改）：上游权威元数据；
2. `data/sites/*.json`（人工维护）：覆盖项，字段全部可选；
3. `src/lib/sites.ts`：left join 合并，产出 `Site[]`。

## 理由

- 上游新增图标时只需跑一次 `sync:icons`，不会与人工数据产生冲突；
- 人工数据只写差异，文件小、diff 清晰、PR 易评审；
- 未被人工维护的条目依然可以被收录（满足「全量覆盖」目标），并标记为 `curated: false` 待认领。

## 代价与缓解

- 自动归类可能不准 → 由 `category` 覆盖字段纠正，且分类关键词表可持续优化；
- 未覆盖条目信息较薄 → 校验脚本输出「待认领清单」，引导社区贡献。
