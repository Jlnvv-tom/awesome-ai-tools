# ADR-0009：放宽图标来源，建立自主收录管线

- 状态：Accepted
- 日期：2026-09-12
- 相关：[ADR-0001](./0001-icon-rendering.md)、[ADR-0008](./0008-icon-theming.md)、[ADR-0002](./0002-data-layering.md)

## 背景

竞品调研显示本站的结构性短板是**收录量被上游锁死**：

| 站点               | 收录量  | 主要壁垒                                |
| ------------------ | ------- | --------------------------------------- |
| AI工具集 ai-bot.cn | 1000+   | 二级细分分类 + 条目中文简介 + 内容矩阵  |
| Toolify            | 30000+  | 月访问量/增长榜                         |
| 本站               | **322** | 全部条目由 `@lobehub/icons` 的 toc 派生 |

代码层面的成因很直接：`getAllSites()` 是 `ICON_META.filter(...).map(...)`，
条目集合的上限等于图标库大小；`SiteSchema` 还要求 `iconId` 必填。

## 决策

1. **新增第三类数据源 `CatalogEntry`**（`data/catalog/*.json`）：
   与 `SiteOverride`（补充 lobehub 条目、以 iconId 关联）不同，每条记录自成完整条目，
   合并进 `getAllSites()` 并以 `id` 去重（冲突由 `validate:data` 拦截）。
2. **图标来源放宽为三级降级**：`lobehub`（CDN）→ `favicon`（构建期抓取的本地图标）
   → `initial`（品牌色首字母块）。派生为 `Site.iconSource` 与 `Site.faviconUrl`，
   由 `resolveIconPlan()` 决定渲染候选链。
3. **favicon 不参与单色化**：它是第三方图像，透明通道不可控，
   用 mask 描边可能得到实心方块。单色风格只作用于图标库图标。
4. **只接入客观公开指标**：目前仅 GitHub Star（`pnpm sync:metrics`），
   不使用任何第三方流量估计或用户行为数据。
5. **排序口径仅四类**：默认权重、最新收录、Star、名称（`src/lib/sorting.ts`）。

## 理由

- **解耦上游**：收录不再依赖 lobe-icons 的合并节奏，贡献者可直接提交；
- **零成本图标**：favicon 由构建期脚本抓取入库，避免新增外部图片服务依赖；
- **保持中立**：`Star` 与 `是否开源`/`定价` 同属可公开验证的事实，不构成竞价排序；
- **向后兼容**：lobehub 派生条目的行为完全不变（`iconSource` 默认 `lobehub`）。

## 约束与代价

| 约束       | 说明                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| id 冲突    | catalog 条目 id 必须全局唯一，`validate:data` 同时校验与图标库派生 id 的碰撞   |
| 图标时效   | 抓取的 favicon 会随官网改版过期，需人工/定期重跑 `pnpm fetch:favicons --force` |
| 图标版权   | favicon 仅用于标识对应工具，归属各权利主体；移除条目时需一并删除本地文件       |
| 指标非实时 | Star 数由脚本定期同步，页面不展示「实时」语义；`--check` 只校验结构而非时效    |
| 客户端体积 | `faviconUrl` 已随 `Site` 下传，搜索索引仅在非 lobehub 来源时写入，避免索引膨胀 |

## 备选方案

| 方案                                | 否决原因                                           |
| ----------------------------------- | -------------------------------------------------- |
| 继续等 lobe-icons 收录              | 无法控制上游节奏，收录量长期停在 322               |
| 只收 lobehub 已有图标、拒绝其他工具 | 与「做完整导航站」的目标冲突                       |
| 引入月访问量等第三方流量数据        | 需外部付费源，且与「不使用流量估计」的中立约束冲突 |
| favicon 一律下载后转 PNG            | 需引入图像处理依赖，收益不足以抵消复杂度           |
