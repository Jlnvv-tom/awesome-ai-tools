# 无障碍走查报告（M3）

- 走查时间：2026-09-10
- 范围：`src/app/**`、`src/components/**`、`src/app/globals.css`
- 依据：WCAG 2.1 AA（键盘可达、语义结构、ARIA、对比度、动效降级）

## 结论

总体状况良好：全站为语义化 HTML、装饰性图形已 `aria-hidden`、图标按钮均带 `aria-label`、
`prefers-reduced-motion` 已在全局降级。本轮共修复 3 类问题（见下表），其余为观察项。

## 已修复问题

| 级别 | 位置                                          | 问题                                                    | 修复                                                                  |
| ---- | --------------------------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------- |
| 严重 | `src/app/layout.tsx`                          | 缺少「跳到主内容」入口，键盘用户需多次 Tab 才能越过顶栏 | 新增 `sr-only` 跳转链接（聚焦时可见），并为 `<main>` 增加 `id="main"` |
| 中等 | `src/app/home-explorer.tsx`                   | 分类筛选按钮仅用颜色表达选中态，读屏无法获知状态        | 为「全部」与各分类按钮补充 `aria-pressed`                             |
| 中等 | `src/app/category/[slug]/category-filter.tsx` | 标签筛选按钮同上                                        | 为「全部」与各标签按钮补充 `aria-pressed`                             |

## 走查通过项

| 维度       | 结论                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------- |
| 语义结构   | 每页单一 `h1`（首页 Hero、详情页标题），区块标题统一为 `h2`；列表使用 `ul/li`                                   |
| 交互元素   | 全部使用原生 `button` / `a`，未用 `div` 模拟；卡片为「覆盖式链接」结构，未出现 `button` 嵌套在 `a` 内的非法 DOM |
| 图标按钮   | 主题切换、搜索、收藏、视图切换均带 `aria-label`；收藏与视图切换带 `aria-pressed`                                |
| 纯装饰图形 | `BrandIcon` 使用 `alt=""` + `aria-hidden="true"`                                                                |
| 键盘可达   | 卡片链接、筛选按钮、弹窗均可 Tab 聚焦并具备 `focus-visible` 焦点环                                              |
| 对比度     | 暗色模式 `--muted-foreground`（240 9% 66%）在 `--background`（240 20% 5%）上约 7:1，满足 AA                     |
| 动效       | `globals.css` 已全局声明 `prefers-reduced-motion: reduce` 降级（动画/过渡/滚动行为）                            |
| 表单       | 首页筛选框与搜索面板输入框均带 `aria-label`，父容器有 `focus-within` 提示                                       |
| 弹窗       | 搜索面板与快捷键总览均提供 `DialogTitle`（搜索为 `sr-only`）作为可访问名称                                      |

## 观察项（本轮不修改）

| 项                 | 说明                                                                            |
| ------------------ | ------------------------------------------------------------------------------- |
| 收藏页加载骨架     | 使用 `animate-pulse` 占位，建议后续增加 `aria-busy` 与 `role="status"` 提示     |
| 主题切换首帧       | `mounted` 前固定渲染月亮图标，属视觉一致性问题，不影响读屏（已有 `aria-label`） |
| 依赖本地数据的区块 | 「我的常用」在 `ready` 前不渲染，避免闪烁；首屏无内容不影响读屏顺序             |

## 回归方式

后续改动请至少自查：

1. 新增可点击元素是否为原生 `button` / `a`；
2. 新增图标按钮是否带 `aria-label`，切换类是否带 `aria-pressed`；
3. 选中态是否同时具备非颜色线索（文本、`aria-pressed` 或图标）；
4. 新增动效是否被 `prefers-reduced-motion` 覆盖。
